# Hello World Programs

This directory contains Hello World implementations in multiple programming languages.

## Execution Instructions

### Python

Run the Python Hello World program:

```bash
python3 hello-world/hello.py
```

Or make it executable and run directly:

```bash
chmod +x hello-world/hello.py
./hello-world/hello.py
```

### JavaScript (Node.js)

Run the JavaScript Hello World program:

```bash
node hello-world/hello.js
```

Or make it executable and run directly:

```bash
chmod +x hello-world/hello.js
./hello-world/hello.js
```

## Requirements

- **Python**: Python 3.x
- **JavaScript**: Node.js
