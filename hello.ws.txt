# Whitespace "Hello World" Program - Visible Representation

Whitespace is an esoteric programming language where only spaces, tabs, and linefeeds are meaningful.
All other characters are ignored, making programs appear completely blank in regular text editors.

This file shows the visible representation of hello.ws using the notation:
- [Space] = space character
- [Tab] = tab character
- [LF] = linefeed (newline) character

## How Whitespace Works

Whitespace uses three instruction types:
- Stack Manipulation (starts with [Space])
- Arithmetic (starts with [Tab][Space])
- Heap Access (starts with [Tab][Tab])
- Flow Control (starts with [LF])
- I/O (starts with [Tab][LF])

Numbers are encoded in binary using [Space] for 0 and [Tab] for 1, terminated by [LF].
